# Status Reference

This document acts as a reference for the statuses that are introduced in this mod.

| Done? | Name | Decreases | Effect |
|:-:|:-:|:-:|:-:|
| No | Inner Fire | No | At the beginning of each turn, gain X immolation. |
| No | Immolation | No | If immolation is 5 or more, Valks' cards become blazing, but cards end your turn when played. |
| No | Elementary | No | Each turn, the first X times you play a basic card, do its actions an additional time. |
| No | Zealous | No | Each turn, the first X times you play a card, do its actions an additional time. |
| No | Chilled | No | The first X cards played when the immolation threshold is reached do not end your turn. |
| No | Eternal Flame | No | Blazing cards no longer end your turn when played if the immolation threshold is reached. |
